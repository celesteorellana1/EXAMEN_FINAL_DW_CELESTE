## Prompts principales

2. "Ayudame con el codigo para server.js."

3. "Ayúdame a desarrollar el frontend en React para iniciar sesión, registrar incidencias y mostrar los equipos."

4. "Ayúdame con el estilo, quiero que tenga colores formales."

5. "Ayúdame a verificar que los usuarios solamente puedan cerrar las incidencias que ellos crean."
